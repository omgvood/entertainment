## Agent skills

Перед началом задачи определи тип по таблице в `docs/agents/skills-routing.md`, назови скилл и путь для артефактов вслух, с обоснованием. Неочевидно — спроси.

## Локализация до первой правки

Даже когда тикет расписан подробно и содержит раздел «Кто зависит» — **это гипотеза прошлой сессии, а не проверенный факт.** До первой правки сделай собственный поиск:

- греп по **символу** (имя функции, константы, типа) — находит рантайм-потребителей;
- греп по **значению** (литерал, строка в интерфейсе, текст ошибки) — находит тесты, документацию и места без импорта;
- результат — короткая таблица «место / что делает / меняется ли».

Тесты считаются потребителями: они ломаются первыми, а место без теста уедет в `master` молча.

В `## Answer` тикета запиши строку `Локализация: <команда>, найдено N мест` — иначе на ревью не видно, был ли шаг сделан.

**Сломалось, если:** тест упал после правки, а его файл не был назван в тикете; греп по значению после закрытия тикета находит места со старым смыслом.
