## Not yet specified

- **Правки данных по итогам тикета 02:** площадки «не в городе» и «Не указано», `image_url`, которые не картинки, обрезка описаний, формулировка счётчика, тип «Выставка» у экскурсий `tickets.museumperm.ru`. Сколько тикетов и в каком слое — станет ясно из `## Answer` тикета 02.
- **Код по решениям тикетов 10, 11, 12** — заводится после каждого решения.
- **Фильтры по сценариям** («бесплатно», «с детьми», «на улице», «для пары»): на карточках эти теги есть, отфильтровать по ним нельзя — в «Ещё фильтры» только цена. Форма чипов-сценариев в p2 оставлена в тумане («Форма чипов-сценариев в вёрстке… Зависит от тикета 05»). Возвращаться после тикета 05 этой карты.
- **Не проверено 2026-09-22:** меняются ли числа у кнопок дат при поиске и выборе категории (при `?q=zzzqqq` кнопки показывали прежние 15 / 62, но это не сверялось с кодом); запоминает ли `/` выбранный город (корень всегда вёл на `/perm`).

## Out of scope

- **Тёмная тема** — пользователь отложил на потом, отдельным эффортом. Спек палитры держит все цвета в токенах `globals.css`, чтобы тёмный вариант добавлялся там же.
- **Шрифт** (Geist) — не обсуждался как проблема.
- **Парсерные хвосты p2:** код по решениям «Теги: определения, авто-теги, слияние» (09), «Точность типов у direct_api» (12), «Дубли, которые серия не склеивает» (14), «Многодневные события» (15) не был написан и тикетов не имел. Это не UI — отдельный эффорт. 2026-09-22 заведена карта [`p8-parser-decisions-code`](../p8-parser-decisions-code/map.md) с четырьмя тикетами на код по этим решениям. Решения: `docs/superpowers/wayfinder/p2-data-fixes/issues/{09,12,14,15}-*.md`.
- **Не открываются повторно — уже решено в p2:**
  - «Детям» отдельной кнопкой (тикет «Группы типов и формат URL»);
  - цена поверх заглушки без фото (тикет «Карточка без картинки», вариант D);
  - дубли вроде двух событий ДК Калинина 23.09 в 19:00 — решено мириться на фронте (тикет «Дубли, которые серия не склеивает»).
- **Покрытие источников** (сколько событий мы не находим) — карта p4.

## Notes

- **Домен:** фронт `web/` (Next.js 16 SSG, Tailwind v4, фильтрация на клиенте), частично парсер `parser/` и Supabase (`events`, `venues`) — в тикетах 02 и 08.
- **Спек палитры:** `docs/superpowers/specs/2026-09-22-light-palette-design.md` — источник правды для 01, 04, 07.
- **Проверено и отброшено 2026-09-22** (в первом UX-разборе названо ошибками, проверка не подтвердила):
  - «склеенный текст» «БесплатноРегистрация обязательна» — на экране пробел есть (`<small className="ml-1">`), склейку дал `innerText`;
  - «← Все события сбрасывает фильтры» — `BackLink.tsx` восстанавливает фильтры из `sessionStorage`; ложная находка из-за прямого перехода на страницу события.
- **Чем заканчивается тикет** (как в p2): `task` — правка с проверкой; `grilling` — записанное решение, код отдельным тикетом; `research` — факт из первоисточника; `prototype` — артефакт, на который смотрят глазами.
- **Параллельность:** каждый тикет — своя ветка от `master`, свой PR. Перед `git add` отдельным шагом `git branch --show-current`. Force-push запрещён, пуш — только с согласия пользователя.
- **БД:** чтение — через Supabase MCP; запись и миграции (тикет 08) — отдельным согласием.
- **Скилл `modern-web-guidance`** при запуске 2026-09-22 сообщил, что устарел (установлена версия 2026_05_16, есть 2026_09_04) — обновить до тикетов, где он нужен (03, 07, 10).
