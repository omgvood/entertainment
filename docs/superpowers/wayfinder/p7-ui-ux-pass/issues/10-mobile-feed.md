## Цифры

На 2026-09-22, ширина 375, `/perm`, прогнано в браузере:
- первая карточка начинается на 526 px из 812 — фильтры занимают две трети первого экрана;
- ширина карточки 161.5 px, 2 колонки, название обрезается после ~12 символов («Интерактивная прогулка «По…»);
- `?date=all`: 268 карточек, высота документа 80 640 px.

README п. 19 (2026-09-19): страница ~114 000 px, высота карточки ~509 px — до схлопывания серий.
