## Question

Три мелкие ошибки отображения, найденные 2026-09-22 на `/perm`:

1. **Поповеры фильтров.** Escape не закрывает ни «Ещё N», ни «Ещё фильтры», и оба можно открыть одновременно — они накладываются друг на друга.
2. **Падеж города.** «Досуг в Пермь — всё в одном месте» на главной и «Куда сходить в Пермь» на странице площадок: в текст подставлено название в именительном падеже, а нужно «в Перми». «В Сочи» не склоняется, поэтому ошибка видна только в Перми.
3. **Падеж площадки в `alt`.** «Вечер фортепианной музыки… — Концерт в Органный зал»: названия площадок не склоняются автоматически, конструкция «в ${venueName}» даёт ошибку почти всегда.

## Контекст

- Поповеры: `web/components/FilterBar.tsx:17-18` — два независимых `useState` (`moreOpen`, `moreTypesOpen`); Escape обрабатывается только в поле поиска (`:65`, очищает запрос). Попапы: `:135`, `:155`.
- Вариант решения на выбор сессии: нативный `popover` (Escape и закрытие по клику снаружи встроены, одновременно открыт один `popover="auto"`) или ручной обработчик. Перед выбором — гайд `modern-web-guidance` по поповерам (скилл просил обновиться: версия 2026_05_16, есть 2026_09_04).
- Падеж города: `web/components/CityView.tsx:215`, `web/components/VenuesCatalog.tsx:34`. Родительный падеж уже есть — `cityGenitive()` в `web/lib/venue-meta.ts:19`; предложного нет. Названия городов — `CITY_CONFIG` в `web/lib/types.ts:35`.
- `alt` с «в ${venueName}»: `web/components/EventCard.tsx:55`, `web/app/perm/events/[slug]/page.tsx:83`, `web/app/sochi/events/[slug]/page.tsx:85`. Площадки из БД не склоняются — нужна конструкция без предлога, например «Концерт, Органный зал».
- **Пересечение:** тикет 07 (реализация палитры) правит те же `FilterBar.tsx`, `EventCard.tsx` и обе `[slug]/page.tsx`. Этот тикет идёт в волне 1, раньше, — 07 делает rebase.
- Проверено и отброшено 2026-09-22: «← Все события сбрасывает фильтры» — ложно. `web/components/BackLink.tsx` восстанавливает фильтры из `sessionStorage`; при клике из ленты `?date=weekend` ссылка ведёт на `/perm?date=weekend`. В разборе страница открывалась прямым переходом, без клика.
