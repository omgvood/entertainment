## Question

При разборе `/perm` 2026-09-22 на карточках нашлись шесть странностей. Каждая замечена на одном-двух примерах. Для каждой нужно выяснить: сколько таких событий, из каких источников, где причина (источник, экстракция, фронт) и какая правка и в каком слое её закрывает.

1. **Площадка не в городе.** «Матч Кубка России: «КАМА» 🆚 «Волжанин» (Кострома)», 23.09 18:30 — площадка и адрес «Кострома». Похоже на выездной матч, попавший в афишу Перми, или на город соперника, принятый за площадку.
2. **Площадка «Не указано».** «Бесплатный мастер-класс по бриджу», 23.09 — `venue_name` = «Не указано», хотя адрес есть: «ул. Екатерининская, 75, офис 414А».
3. **`image_url`, которые не картинки:** посты `t.me/<канал>/<id>`, страницы `vk.com/<группа>` и `vk.com/<группа>/wall-…`, VK-заглушка `vk.com/images/camera_50.png`, рекламный редирект `goodsbuy.by/redirect/cpa/…`. Фронт их отсекает в тикете 07 (реализация спека), но в базе они остаются.
4. **Описание обрезано посреди слова.** Киноклуб «Ностальжи» — текст кончается на «…готовится встречать императора Алексан».
5. **Счётчик не сходится.** Заголовок: «255 событий в афише», а на «Все даты» 268 карточек. Гипотеза: счётчик считает уникальные события (серии схлопнуты), а лента — показы по дням. Если так, это вопрос формулировки, а не данных.
6. **Тип не совпадает с названием.** «Экскурсия «Пространство пермской истории с древнейших времен до начала XX века»» (Дом Мешкова, 23.09) помечена как «Выставка»; `source_url` — `tickets.museumperm.ru/ticket/2656`. Это не `permm` и не `permopera` из решения p2 «Точность типов у direct_api» — отдельный источник. Проверить, сколько у него событий с типом, противоречащим названию.

select split_part(split_part(image_url, '://', 2), '/', 1) as host, count(*)

where city = 'perm' and (date >= to_char(current_date, 'YYYY-MM-DD') or date = 'always')

-- п.3: адреса, которые не картинки, по источникам
select source, count(*)
from events
where city = 'perm' and date >= to_char(current_date, 'YYYY-MM-DD')
  and (image_url ~ '^https?://(www\.)?(t\.me|vk\.com)/' or image_url ilike '%/redirect/%')
group by 1 order by 2 desc;

-- п.2: площадка «Не указано» и похожие
select source, venue_name, count(*)
from events
where city = 'perm' and date >= to_char(current_date, 'YYYY-MM-DD')
  and (venue_name ilike 'не указ%' or venue_name = '' or venue_name is null)
group by 1, 2;

-- п.4: пик длины описаний (обрезка по фиксированному лимиту даст всплеск на одной длине)
select length(description) as len, count(*)
from events
where city = 'perm' and description is not null
group by 1 order by 2 desc limit 10;

-- п.1: события, где площадка или адрес указывают на другой город
select title, venue_name, address, source, source_url
from events
where city = 'perm' and date >= to_char(current_date, 'YYYY-MM-DD')
  and (venue_name ilike '%кострома%' or address ilike '%кострома%');
