## Question

1. **404 без навигации.** Удалённое событие отдаёт стандартную 404 Next.js на английском, без шапки и ссылок — `app/not-found.tsx` нет.

4. **Шапка.** На событиях Перми `<Header />` без `city` — город не подсвечен. Логотип ведёт на `/`, а `/` постоянно редиректит на `/perm`: пользователь Сочи попадает в Пермь. Надпись `.PRM` стоит и на страницах Сочи.

## Контекст

Строки перепроверены 2026-09-29 на `master` `34b5825`:

- 404: `app/not-found.tsx` и `app/*/not-found.tsx` отсутствуют. `notFound()` вызывается в `app/perm/events/[slug]/page.tsx:67` и `app/sochi/events/[slug]/page.tsx:69`. Неизвестный URL вне сегмента города попадает в корневой `not-found`; `notFound()` внутри `app/perm/…` — в ближайший `not-found.tsx` сегмента.
- Прошедшее событие: `generateStaticParams` строит только будущие (`[slug]/page.tsx:33`), остальные рендерятся по запросу через `getEventBySlug` без фильтра по дате. `getCityToday` уже импортируется на странице (`:5`, `:69`/`:71`). Парсер держит прошедшие события 1 день: `cleanup_old_events(days_to_keep=1)`, `parser/src/parser/db.py:211`.
- Гидрация: `web/components/CityView.tsx:39` — `useState(() => getCityNowMinutes(city))`, при этом `today` приходит пропом со сборки (`:32-36`) и пересчитывается эффектом (`:50-58`). От `nowMinutes` зависят `countAvailable` (`:103`), `sortForDisplay` (`:117`), метки в `EventCard`. Комментарий `web/lib/filters.ts:1-5` («mismatch невозможен») устарел.
- Шапка: `web/components/Header.tsx:4` (`city?: City`), `:9` (`href="/"`), `:14` (`.PRM`). `<Header />` без города — только `app/perm/events/[slug]/page.tsx:75`; остальные 7 вызовов передают `city`. Редирект `/` → `/perm` — `web/next.config.ts:4-9`.
- **Пересечения:** p7/03 (backlog) правит `EventCard.tsx` и обе `[slug]/page.tsx` (`alt`); p7/07 (палитра) — те же файлы и `Header.tsx`; p7/09 — заголовок «сегодня» на главной (близкий к п. 1.4 аудита, в этот тикет не входит). Этот тикет раньше обоих — они делают rebase.

**Решения, принятые при заведении** (сессия может их пересмотреть только с согласия пользователя):

- Гидрация — `nowMinutes` считается при сборке на странице города и передаётся в `CityView` пропом, как `today`; эффект после монтирования пересчитывает его, как сейчас. Вариант «`null` до монтирования» не берём: `sortForDisplay` и `countAvailable` без значения не работают.
- 404 — корневой `app/not-found.tsx` (шапка без выбранного города, ссылки на `/perm` и `/sochi`) и `not-found.tsx` в сегментах `app/perm/events/[slug]/`, `app/sochi/events/[slug]/` (шапка и ссылка на афишу своего города). Текст на русском.
- Прошедшее событие — только плашка «Событие прошло» и ссылка на афишу города. Хранение прошедших событий 30–90 дней и блок «Что есть сейчас» (аудит 1.5, п. 2) — не здесь: это парсер и отдельное решение, остаётся в тумане карты.
- Логотип ведёт на `/${city}` при заданном городе, без города — на `/`. Надпись — без кода города.
