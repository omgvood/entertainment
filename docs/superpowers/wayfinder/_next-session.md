1. **p9/01** — пользователь сделал шаги (см. «Отложено»). Тогда сессия проверяет на `/perm` `window.ym` и оба мета-тега, закрывает тикет.

## Отложено

- **Timepad 403 в CI (p9/02):** в CI тело ответа — челлендж Cloudflare «Just a moment...», а с домашнего IP без токена API отвечает JSON `403 "Запрос требует указание токена"` (проверено 2026-09-29). 30.09–03.10 `source_health` стабильно даёт `timepad: HTTP 403` по Перми и Сочи. Гипотеза: блок по IP раннера GitHub, новый токен может не помочь. Шаг пользователя — продлить токен (не сделано).
- **Статус `parse.yml` необъяснён:** красные прогоны 27.09–01.10 (лог 01.10: sochi `failed=1`, exit 1, единственная ошибка — Timepad 403), зелёные 02.10 и 03.10 при том же Timepad 403 в sochi (и ещё одной ошибке telegram-posts 02.10). Почему exit code разный — не выяснено; читать код `pipeline.py`/`cli.py` и логи прогонов 02.10 и 03.10. Кандидат в туман карты p9.
- **Telegram-алерт, возможно, не настроен:** в шаге уведомления `parse.yml` `TG_BOT_TOKEN`/`TG_CHAT_ID` в логе пустые (заданный секрет показывался бы как `***`). Гипотеза, не проверена. Связано с p9/02.
