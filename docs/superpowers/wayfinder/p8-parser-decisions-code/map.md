**Эффорт закончен, когда:** все четыре тикета закрыты кодом (или, если проверка перед правкой опровергнет решение p2, — переоткрыты как grilling с новым ответом, а не молча переписаны).

## Notes

- **Домен:** парсер (`parser/src/parser/`) — извлечение (`extraction/`), источники (`sources/`), валидация (`validator.py`), слияние дублей (`merge.py`, `fuzzy.py`), таксономия тегов (`taxonomy.py`). Тесты — pytest (`parser/tests/`).
- **Источник решений:** карта `p2-data-fixes` (закрыта 2026-09-22), тикеты 09, 12, 14, 15 — `## Answer` каждого содержит фразу «код — отдельным тикетом», код не написан.
- **Локализация обязательна до первой правки** (`CLAUDE.md`) — грепом по символу и по значению; строки, указанные в p2-тикетах и здесь, снимок на 2026-09-22, перепроверить перед правкой.
- **Перепарсинг.** Тикеты 02 и 04 требуют перепарсинга после мержа (02 — подъём `TAGS_VERSION`, 04 — фестивали доберут дни на следующем ежедневном прогоне без бэкфилла). Согласовать с пользователем перед стартом прогона.
- **Параллельность:** каждый тикет — своя ветка от `master`, свой PR. Перед `git add` отдельным шагом `git branch --show-current`. Force-push запрещён, пуш — только с согласия пользователя.
- **БД:** только чтение через Supabase MCP в рамках этих тикетов — ни один код-тикет не требует миграции.
