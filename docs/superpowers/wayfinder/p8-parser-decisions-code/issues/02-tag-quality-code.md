## Question

Решение «Теги: определения, авто-теги, слияние» принято 2026-09-22 (карта p2, тикет 09) по всем четырём под-вопросам, но тикет на код не был заведён. На `master` 2026-09-22: промпт без определения тега «для пары»; `validator.py` подставляет авто-теги по типу всем источникам с пустыми тегами, а не только `direct_api`/social-source; `merge.py` объединяет противоречивые пары тегов вместо приоритета строки-победителя; `TAGS_VERSION` не поднят.

## Контекст

- Решение: `docs/superpowers/wayfinder/p2-data-fixes/issues/09-tag-quality.md`, `## Answer`. Четыре пункта:
  1. Промпту — определение тега «для пары»: «камерное/романтическое мероприятие на двоих (свидание), не для компании и не для семьи с детьми». Остальные 10 тегов не трогать.
  2. Условие подстановки авто-тегов в `validator.py` — только для source, начинающегося с одного из `SOCIAL_SOURCE_PREFIXES` (`vk-`, `telegram-`, `generic`), не для всех источников с пустыми тегами.
  3. При слиянии дублей конфликтующая пара тегов (`вечером`/`днём`, `в помещении`/`на улице`) — побеждает тег строки-победителя по `priority`, не объединяется.
  4. Поднять `TAGS_VERSION`, перепарсить.
- Локализация повторным грепом 2026-09-22 подтвердила пути и строки из `## Answer` p2/09: промпт с закрытым набором тегов — `parser/src/parser/extraction/deepseek_extractor.py:63,98`, `groq_extractor.py:74,109`, `gemini_extractor.py:49,83` (по два места в каждом файле, системный + пользовательский промпт).
- `validator.py:81-83`: комментарий уже утверждает «direct_api источники не проставляют теги — подставляем авто-теги по типу», но условие (`if not data["tags"]:`) не проверяет источник вообще — применяется ко всем. Готовый признак есть: `SOCIAL_SOURCE_PREFIXES` из `config.py:28`, уже используется тем же способом в `is_spurious_always` (`validator.py:33`). Новое условие: `not any(source.startswith(p) for p in SOCIAL_SOURCE_PREFIXES)`.
- `merge.py:65-73` (`_enrich`): текущий код объединяет теги без разбора конфликтов (`union: list[str] = list(winner.tags)` + добавление тегов проигравших). Нужно исключить конфликтующую пару у проигравшего перед объединением.
- `taxonomy.py:9`: `TAGS_VERSION = 1`.
- Источник фактов: p2, тикет «Проверка «бесплатно» по источникам» не про теги — факты по точности тегов внутри самого p2/09 (для детей ≈90%, для пары 40-60%; 9/13 ошибок «вечером» — авто-тег `concert → вечером` не на `direct_api`).
- Тикет 01 этой карты (direct_api-маппер типов) чинит источник данных для авто-тегов у `permopera`/`permm` — не блокирует этот тикет технически (разные файлы), но снижает будущий шум после перепарсинга, поэтому идёт первым в волне.
