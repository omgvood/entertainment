## Question

`EmptyState` в `web/components/CityView.tsx` (версия P1) говорит «На эту дату ничего не нашлось. Выберите другой день в ленте выше» и предлагает кнопку «Ближайшее». Когда у города нет событий вообще, выбирать нечего: кнопки нет, а совет остаётся.

## Контекст

- P1 уже починил старую проблему: текст больше не ссылается на удалённые контролы, кнопка сброса показывается только при активных фильтрах. Остался случай «город пуст».
- Сейчас в Сочи 2 события, после тикета 03 будущих не останется — случай станет рабочим, а не гипотетическим.
- Сигнал для различения уже есть в компоненте: `suggestion === null` и пустой список событий города.

## Готово когда

- Для города без событий текст говорит именно это и не предлагает выбрать другой день.
- Остальные пустые состояния (фильтры, поиск, конкретная дата) не изменились.
- `npm run lint`, `npx tsc --noEmit` зелёные; оба состояния проверены в превью.

## Answer

Локализация: `rg "EmptyState|suggestion" web` (по символу) — 1 место, `web/components/CityView.tsx` (единственный потребитель, других мест использования `EmptyState`/`suggestion` в проекте нет); `rg "Ближайшее|ничего не нашлось|Выберите другой день"` (по значению, весь репозиторий) — найдено 4 места: сам компонент и три файла документации (этот тикет и два plan-файла в `docs/superpowers/plans/`), которые не рантайм-код и правки не требуют.

Правка: `EmptyState` в `web/components/CityView.tsx` получил проп `cityEmpty={suggestion === null && liveEvents.length === 0}` (сигнал, названный в тикете). При `cityEmpty === true` заголовок меняется на «В городе пока нет событий», строка про выбор другого дня скрывается; кнопка «Ближайшее» и так не рендерится, потому что `suggestion === null`. Остальные ветки (`showReset`, кнопка сброса фильтров, `SearchResults`) не тронуты.

Проверка:
- `npm run lint` — чисто (1 неотносящееся предупреждение в `app/layout.tsx` про `<img>`).
- `npx tsc --noEmit` — чисто.
- Превью (`npm run dev -p 3010` в отдельном worktree): `/sochi` — 0 событий в городе, показывает «В городе пока нет событий» без совета и без кнопки. Дату с частично пустым набором (город не пуст, но конкретный день пуст) визуально проверить не удалось — `/perm` стабильно падал с `ECONNRESET` к Supabase в этой песочнице (сетевая проблема окружения, не связана с правкой); код этой ветки не менялся (тот же JSX, что был, просто под `!cityEmpty`).
