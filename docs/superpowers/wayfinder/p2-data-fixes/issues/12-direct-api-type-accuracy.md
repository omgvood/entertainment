# Точность типов у direct_api

Type: research
Status: open
Blocked by: —
Ветка: `research/direct-api-types`

## Question

Насколько верно `direct_api`-мапперы проставляют `type`? Известен один систематический сбой: `permopera` отдаёт экскурсии по театру как `concert`, из-за чего авто-тег вешает на них «вечером».

## Контекст

- Затронутые источники: `permopera` (8 событий), `permm` (9), `timepad` (8), `quizplease` (15).
- Тип напрямую кормит авто-теги (`TYPE_DEFAULT_TAGS`) и будущие группы типов (тикет 05).
- В выборках всплыли: «Цикл авторских экскурсий „Балетный квартал“» и «Экскурсия по театру» с типом `concert`; у `timepad` 7 из 8 событий без тегов, потому что их типы не входят в карту авто-тегов.
- У `quizplease` все 15 событий получают ровно авто-набор `quiz` — здесь ошибки маловероятны, но проверить стоит.

## Как перевести в белое

Выгрузить все события этих четырёх источников (около 40), открыть `source_url` и сверить тип с тем, что написано на странице. Посчитать долю ошибок по источникам и выписать, какие поля провайдера маппер смотрит (`parser/src/parser/sources/permopera.py`, `permm.py`, `timepad.py`).

## Готово когда

В ответе тикета — доля неверных типов по источникам, список конкретных ошибок и вывод, чинить ли маппер, карту авто-тегов или и то и другое.
