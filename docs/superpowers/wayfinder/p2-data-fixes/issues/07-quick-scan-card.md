# Карточка быстрого просмотра

Type: task
Status: backlog
Blocked by: 01, 02, 06, 13

## Question

Собрать карточку под быстрый просмотр: время первой строкой, цена бейджем, меньше строк с эмодзи, пометка «через N ч» по времени города.

## Контекст

- Сейчас `web/components/EventCard.tsx` рисует дату, цену и адрес тремя строками с эмодзи, цена — сырая строка `priceText`.
- Бейдж: `free` → «Бесплатно», `known` при `price_min = price_max` → «600 ₽», при разбросе → «от 440 ₽», `unknown` → без бейджа, строка `price_text` как есть. Доли после тикета 01: 38 / 23 / 39.
- Бейдж собирать из `price_min` / `price_max`, а не из `price_text`: в строках встречаются «27900 руб.» и «от 235.6 млн ₽».
- Картинки нет у 43% событий (у VK — у 64%), поэтому вид карточки без картинки решает тикет 13.
- В `master` у карточки уже есть проп `moreDates` («ещё N дат») и компонент `OtherDates` — правка идёт поверх них.

## Готово когда

- Карточка собрана по решениям тикетов 06 и 13, бейдж покрыт тестами на все четыре случая.
- «Через N ч» считается helper'ом из тикета 02, а не локальным временем браузера.
- `npx vitest run`, `npm run lint`, `npm run build` зелёные; вид проверен в превью на событиях с картинкой и без.
