## Question

Поля `category` и `district` выглядят как опора для фильтров и сценариев, но данных в них нет. Записать это там, где принимаются решения, чтобы на них снова не понадеялись.

## Контекст

- `category` заполнена у 35 из 359 событий свободным текстом: «6+», «english club», «Драма», «Мастер-класс», «art» — единого словаря нет, LLM пишет что хочет.
- `district` заполнен у 3 из 359 событий Перми.
- README, пункт 14 (фильтр по району), предполагает «оценить покрытие поля, потом строить список районов». Оценка теперь есть: без работы парсера фильтр не сделать.
- Блок «Район» в `FilterBar` отрисован с бейджем «скоро» и задизейбленными чекбоксами; P1 его удаляет.

## Готово когда

- В README у пункта 14 стоит замеренное покрытие `district` и вывод, что фильтр упирается в парсер.
- Там же или в `web/lib/types.ts` зафиксировано, что `category` — свободный текст и опорой для фильтров быть не может.
- Правка только документационная, кода не трогает.

## Answer

Локализация: `grep -rn "district"`, `grep -rni "category" web/`, `grep -rn "14\.|Район" README.md` — найдено 3 места. Ключевое расхождение с контекстом тикета: блок «Район» в `FilterBar.tsx` уже отсутствует — P1 его удалил раньше, чем написали этот тикет («P1 его удаляет» в контексте было прогнозом, не фактом). `district` у `VenueItem` (площадки) — живое, заполненное поле, к `EventItem.district` не относится, спутать легко по одинаковому имени. `category` нигде в коде не документирован как отдельное понятие; единственное похожее имя — `_map_category` в `parser/src/parser/sources/timepad.py`, маппинг категорий Timepad в `EventType`, другое поле с тем же словом.

Правки:
- [README.md:2386](../../../../../README.md) — пункт 14 переписан: факт про удалённый блок фильтра, замеренное покрытие `district` (3/359) и `category` (35/359, свободный текст без словаря) с примерами, отдельная строка про несовпадение с `_map_category`.
- [web/lib/types.ts:63](../../../../../web/lib/types.ts) — комментарий над `category?: string` со ссылкой на README, п. 14.

Проверка (документационная правка, тестов нет): `git diff` — изменены только README.md и types.ts (комментарий, без логики); остальные незакоммиченные файлы в рабочем дереве — чужие изменения других тикетов, не тронуты.
