# Цена: `0 ₽` больше не «бесплатно»

Type: task
Status: open
Blocked by: —
Ветка: `fix/price-zero-rub`

## Question

`web/lib/price.ts` считает бесплатными строки `0 ₽` и `от 0 ₽`. LLM пишет их, когда цены не знает, поэтому 70 из 359 событий Перми ложно значатся бесплатными: платные экспозиции Пермской галереи, сольный стендап-тур, фестиваль «Своды», детские циклы галереи. Убрать эти ветки из `FREE_RE`, оставив слова «бесплатн / вход свободн / свободный вход».

## Контекст

- Доли до правки: free 234 (54%), known 102, unknown 99.
- После правки: free 164 (38%), known 102, unknown 169 (39%).
- `priceKind` используется в фильтре цены P1 (`matchesEvent`): сейчас такие события при `pmin > 0` молча прячутся как бесплатные.
- Правило не трогает `price_min` / `price_max` — это только смысл строки.

## Готово когда

- В `web/lib/price.test.ts` есть падавший до правки тест: `0 ₽` и `от 0 ₽` дают `unknown`, «Бесплатно» и «Вход свободный» дают `free`.
- `npx vitest run` и `npx tsc --noEmit` зелёные.
- Шапка-комментарий `price.ts` обновлена: цифры 347/175 устарели.
