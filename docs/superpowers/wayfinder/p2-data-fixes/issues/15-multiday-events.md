# Многодневные события: дата начала и конца

Type: grilling
Status: open
Blocked by: —

## Question

Фестивали лежат одной строкой на дату начала, поэтому со второго дня исчезают из ленты. Решить, как представлять событие, которое идёт несколько дней.

## Контекст

- Примеры в данных: «Пермская Фантасмагория» 1–7 октября (строка на 1 октября), «МОНОфест» 9–12, «Музейные дни» 12–16, фестиваль Спивакова 23–27, цирк «Империя мастеров» 5–20 сентября.
- В схеме есть только `date` (text) — поля конца нет. Выставки при этом приходят строкой на каждую дату, то есть один и тот же смысл выражается двумя разными способами.
- Варианты: колонка `date_end`; разворачивание в строки по дням на стороне парсера; вычисление диапазона на фронте из описания (ненадёжно).
- Влияет на ленту дат P1 (в какой день показывать), на «ещё N дат» и на «идёт сейчас» (тикет 06).
- Цена ошибки в обе стороны: развернуть в дни — «Музейные дни» займут пять дней ленты; оставить одной строкой — фестиваль не найти на третий день.

## Готово когда

Записан ответ: форма хранения, кто её заполняет, что делает фронт и нужен ли бэкфилл. Миграция и код — отдельными тикетами.
