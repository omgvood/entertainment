## Question

Картинки нет у 43% событий (155 из 359; у VK — у 64% событий, 143 из 225). Быстрый просмотр строится вокруг картинки, поэтому нужно увидеть, как выглядит лента, где почти половина карточек без неё.

## Контекст

- Сейчас на месте картинки рисуется плейсхолдер по типу (`web/lib/event-styles.ts`, `CardImage.tsx`) — визуально это большой пустой блок 16:9.
- У 64 событий нет описания, у 37 нет ни картинки, ни описания.
- Варианты для сравнения: плотная текстовая карточка без блока картинки; общий плейсхолдер как сейчас; смешанная сетка, где карточки без картинки ниже.
- Прототип черновой и одноразовый: его задача — дать повод для решения, а не попасть в продакшен.

## Готово когда

Есть черновой прототип (можно статической страницей на реальных данных из БД), пользователь на него посмотрел и выбран вариант. Решение записывается в ответ и питает тикет 07.
