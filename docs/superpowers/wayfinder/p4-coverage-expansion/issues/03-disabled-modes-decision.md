## Question

Три режима парсера в неопределённом состоянии:
- `vk_events` — реализован без LLM, но выключен: `groups.search` требует user-токен вместо текущего сервисного (`README.md:106`).
- `kudago.py` — интегрирован для Сочи, но отключён (по памяти проекта: нет Перми, Сочи устарел — `aggregator-coverage.md`).
- `playwright_listing` — рабочий режим, но сейчас ни один источник на нём не запущен (`README.md:120`); `permopera`/`permm` переведены на `direct_api`.

Каждый — код, который либо стоит довести до продакшена, либо явно списать как мёртвый груз (`Out of scope`). Нужно решение по каждому из трёх, а не общее «оставить как есть».

## Контекст

- `README.md:106`, `README.md:120` — статусы режимов.
- `parser/src/parser/sources/vk.py`, `parser/src/parser/sources/kudago.py`, `parser/src/parser/sources/playwright_fetcher.py`.
- `docs/superpowers/wayfinder/` (память проекта, вне тикета) — `aggregator-coverage.md`: KudaGo не годится по покрытию (нет Перми, Сочи устарел).
