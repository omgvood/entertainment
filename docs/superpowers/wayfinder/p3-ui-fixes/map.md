## Решение

Option A из handoff, расширенный на оба попапа: корневой `<div>` FilterBar разделён на внешнюю обёртку (без `overflow`) и внутреннюю обёртку со скроллом; оба попапа вынесены прямыми потомками внешней обёртки. Отклонённые варианты (Option B — React Portal, Option C — CSS override overflow-y) — см. тикет.

## Notes

- **Домен:** UI FilterBar в `web/components/FilterBar.tsx`, часть агрегатора афиши Перми и Сочи.
- **Источник:** `HANDOFF_FilterBar_zIndex_Issue.md` (temp, вне git) — предыдущая сессия зафиксировала root cause и три неудачные попытки фикса, реализацию не завершила (блокер: требуется JSX-рефакторинг).
- **Скилл на реализации:** `verification-before-completion` — критерий готовности проверяется вручную в браузере на трёх ширинах (1280/768/375), юнит-тестом overflow/CSS не проверить, TDD неприменим.
